# 《遗迹回声 / Echoes of the Buried Relic》

HTML + CSS + JavaScript + Three.js 浏览器第三人称游戏。当前为**三层遗迹新素材整合版**，不是最终课程验收版本。

## 本轮 C2：在 R2 上补齐任务 C（含穿模修复）

- 玩法：三宝物真实挖掘、两处陷阱、生命/无敌、出口、胜败、暂停、重开和菜单；受伤会中断挖掘，同帧不能重新开始。取消采集立即释放其移动锁，不覆盖受伤动作。
- 声音：11 类本地 Web Audio 合成反馈；真实音量/静音，开始点击后恢复音频，暂停/重开清理旧音源，失败不阻塞游戏。
- UI：完整 HUD/菜单/结果、全局音量、帮助、Demo 标识与退出、键盘焦点与响应式样式。
- Demo：输出正常 InputFrame，走两段楼梯、完成三次挖掘、开门并真实到达出口；没有瞬移或修改计数。30/60/120 FPS 和不同镜头朝向的控制器/几何测试约 52 秒通关；20 FPS 也纳入一键回归。
- 碰撞（C2 新增）：楼梯两侧护栏/顶端背面/井口压顶、出口关闭石门、厨房搁架、蓄水池入口、周边碎石共 51 个碰撞补丁与可视模型对齐（纯 manifest 数据，不改 A/B 代码）；专用物理探针扫描与楼梯专项回归防“穿模”和“卡住”。
- 版本标识：单文件菜单显示 **R2 + C 完整功能版 C2**。详细范围、自动测试事实、人工验收步骤及跨模块变更见 `任务C/C2交付与检验.md`。
- **这里的“功能版”不等于课程最终验收通过**：当前环境没有真实浏览器可执行文件，声音听感/画面及真人完整通关须亲自确认，不伪造五人检查、外部试玩或 NO AI 记录。

## 已保留的体验修复 R2

- 已确认人物资产正面为 +Z，与控制器 -Z 约定相反；导入模型旋转180度适配，四方向移动与模型正面回归检查。
- 降低走跑摆幅，肩/髋/膝增加重叠关节连接，减轻低模部件运动时的接缝。
- 使用明确的 sRGB、ACES 色调映射和适度曝光；提高地下环境补光、限制导入点光强度，关闭未经调校的阴影，压低金光透明片遮挡。
- 镜头缩短并降低默认俯角；隐藏藤蔓/苔藓/装饰琥珀等视觉杂物，上层采用剖切显示，碰撞与楼板保持。
- 宝藏新增清晰金晶体与环标记，收集后隐藏标记和原金光/灯；互动按水平距离与严格楼层高度门限判定，显示距离、楼层、站稳/动作锁原因。移动离开或跳起会取消收集，需要回到范围站稳再按 E。
- 尚未在用户浏览器现场复现“完全收不了”的唯一原因；原土堆支持面与三处交互点技术检查本就通过，不虚称已证实是土堆高度问题。请确认新下载文件菜单显示“R2 + C 完整功能版 C2”。

## 1. 最简单的打开方式

下载 `遗迹回声_新素材整合版.html` 到电脑，用新版 Chrome / Edge 打开，然后等待“正在加载”变成“开始游戏”。Three.js、代码、样式、GLB 模型和关卡数据全部内嵌，不需要 Node、服务器、账号或网络服务。平台如果只显示源码，请下载后在本机浏览器打开。

兼容旧文件名 `遗迹回声_B验证版.html` 也更新为同一份整合版。浏览器需支持 WebGL，建议启用硬件加速。加载失败会在页面显示错误；请截图反馈。**尚未做真实浏览器画面验收，不能保证所有设备兼容。**

## 2. 模块源码运行与重新生成浏览版

在本目录执行：

```bash
pnpm install --frozen-lockfile
pnpm start
# 同一台机器浏览器打开 http://localhost:5173/
```

远程课堂工作区的 localhost 不等于自己电脑，需要平台端口转发；没有转发时优先下载上面的单文件版。原始 `index.html` 使用 ES Modules，不能直接双击，需要 HTTP；单文件整合版不受此限制。

```bash
node build-browser.mjs
# 重新生成两个单文件 HTML；使用现有本地 Three.js，无额外构建依赖。
node 任务C/一键检验.mjs
# 无需开服务器；覆盖玩法、UI/音频模拟、输入、Demo、几何与导出脚本。不是真人视觉/听觉验收。
```

依赖锁定 `three@0.170.0`，本轮环境 Node v24.19.0 / pnpm 11.22.0。首次安装无缓存时需联网；安装后游戏不依赖 CDN、实时 AI 或远程后端。

| 移动 | WASD / 方向键 |

## 4. 新素材接入进度

原始输入目录：`../遗迹回声_地刺版/`。模型保持原尺寸、Y 向上坐标，不把三层地图压成平地。

- 三层地下遗迹楼面高度为 0、-5、-10 米；出生点 `[0,0,11.5]`，三层出口 `[0,-10,13]`。
- 已加载完整场景、内嵌纹理和局部灯光；旧灰盒地面/柱/宝物标记不再叠加。
- 已加载女性角色 GLB，利用肩、髋、膝及躯干节点做待机、走跑、跳跃、挖掘、受伤和胜利程序动作。没有伪称模型自带动画片段。
- 90 个清单实体 AABB、702 个楼板代理、2 段连续楼梯坡面和真实土堆网格提供碰撞/地面支持；按身体高度区分楼层，伤害触发区不当墙。
- 两段楼梯支持上下行，洞口支持自然下落；跳跃使用重力和子步，盒顶可作落地支持。
- 相机新增环境遮挡射线缩短，地下楼层不再被旧的 y=0 镜头高度限制拉回地表。
- 土堆/木盒复用场景节点，不再生成蓝晶体。站稳按 E 后真实计时收集，土堆范围 2.3 米、木盒 1.9 米；三维距离避免跨层互动。收集后保留容器和碰撞，熄灭其材质自发光。
- 静态地刺使用真实三维身体触发与两帧扫掠，伤害为游戏规则每次 1 点，含无敌间隔；已连接生命、失败、重开和三层出口判定。
- 启动会等待场景及人物加载完毕。失败明确报错，不偷偷显示旧灰盒代替成功。

本次按用户要求跨模块集成，涉及 A 的场景/关卡/主循环、B 的人物/镜头和 C 的宝藏/伤害/出口适配。`environment.ready/surfaces/cameraObstacles`、`player.ready` 及相机可选 `obstacles` 是新增的集成接口，旧同步启动方式不再适用。

## 7. 建议你现在验证

1. 下载新整合版，等加载结束后开始，确认是新遗迹与新人物，而不是旧方块角色。
2. 测 WASD、拖动镜头、跑步、跳跃；检查人物面向与动作。
3. 找金光土堆靠近按 E，观察挖掘动作与计数是否只增加一次。
4. 找两侧楼梯上下楼，观察是否悬空、穿墙、卡台阶或镜头穿顶。
5. 二三层木盒按 E，检查不能隔着楼板互动；检查地刺伤害和重开复位。
6. 集齐三件后尝试三层出口；将实际问题的操作步骤、截图或录屏反馈。

## 8. 已知限制与素材来源

- 控制器是自定义简化碰撞，不是完整物理引擎；狭角、头顶与盒盖边缘仍需实机复测。
- 镜头用中心射线处理遮挡，不等于完整相机球体碰撞，狭窄空间仍可能近距离遮挡。
- 掉出低于 -25 米的异常区域会回出生点；这是防无限下落保护，不用于 Demo 或通关。
- 原资产静态金光含透明片和局部灯光，收集只调整容器材质自发光，尚需视觉确认残余金光是否符合设计。
