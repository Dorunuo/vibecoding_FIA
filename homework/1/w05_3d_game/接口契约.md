## 1. 全局约定（所有成员必须一致）

- 原生 JS **ES Modules** + Three.js；不用 TypeScript/Godot。
- Three.js 用 `import * as THREE from 'three'`（由 index.html 的 importmap 解析）。
- 坐标：**Y 轴向上，地面 `y=0`，1 单位 ≈ 1 米，角色初始前方为 `-Z`（yaw=0 面向 -Z）**。
- 位置配置统一写 `[x, y, z]` 数组，进入模块后再转 `THREE.Vector3`。
- 速度单位：单位/秒；角度：弧度；相机/角色朝向变量统一命名 `yaw`。
- `dt` 单位秒，主循环已限制 `Math.min(clock.getDelta(), 0.05)`。
- **除 `main.js` 外的模块不得自行 `requestAnimationFrame`、不得创建第二个 renderer/scene/主循环。**
- 模块公开快照中的位置是**副本**，他人不得通过快照改写角色位置。

## 4. 各模块接口（已冻结，勿改名/改参数/改返回结构）

### 4.1 `scene.js`（A）— `createEnvironment(container)`

```js
{
  scene,        // 全项目唯一 THREE.Scene
  renderer,     // 全项目唯一 THREE.WebGLRenderer
  colliders,    // StaticCollider[]：{ id, minX, maxX, minY, maxY, minZ, maxZ }
  reset(), update(dt, elapsed), resize(width, height), dispose(),
}
```

### 4.2 `input.js`（B）— `createInput(targetElement)`

```js
{
  readFrame(),     // 每帧一次，返回 InputFrame
  reset(),         // 清空按键/边沿（重开/失焦）
  setEnabled(flag),// 只关角色移动/互动；暂停/取消等全局键仍可用
  getLastDevice(), // 'keyboard' | 'mouse' | 'gamepad'
  dispose(),
}
// InputFrame（人工与 Demo 完全同构，勿改字段）：
{
  moveX, moveY,             // [-1,1]
  lookX, lookY,             // 本帧角度增量(弧度)，已在 input 内处理灵敏度
  jumpPressed, interactPressed, sprintHeld,
  pausePressed, confirmPressed, cancelPressed, // Pressed 是边沿事件
}
```

### 4.3 `player.js`（B）— `createPlayer({ scene, spawn })`

```js
{
  group,                                   // THREE.Group，已加入 scene
  reset(spawn),                            // 唯一允许外部重置位置的常规方法
  update(dt, input, world),               // 返回 PlayerEvent[]（type: step|jump|land）
  getSnapshot(), playAction(name, duration, options = {}), dispose(),
}
// update 的 world = { colliders, cameraYaw, bounds, playerRadius }
// getSnapshot 返回：{ position(Vector3副本), yaw, speed, grounded, action, controlLocked }
// playAction: 只控制视觉与移动锁，不收集/扣血/胜利；C 不得改写 group.position/speed。
```

### 4.4 `camera.js`（B）— `createFollowCamera({ aspect })`

```js
{ camera, yaw, reset(playerSnapshot), update(dt, playerSnapshot, input), resize(w,h), dispose() }
// 相机只读快照，不改角色位置；lookX/lookY 不重复乘 dt。
```

### 4.5 `gameplay.js`（C）— `createGameSession({ scene, level })`

```js
{
  start(mode), restart(), returnToMenu(), togglePause(),
  update(dt, input, playerSnapshot, playerApi),  // 返回 GameEvent[]
  getSnapshot(), dispose(),
}
// getSnapshot 至少返回：
{
  state, mode, collected, total, health, maxHealth, exitOpen,
  objective, interactionPrompt, resultMessage,
  treasures: [{ id, state, position }],  exit: { position, open },
}
// GameEvent type ∈ dig|collect|hurt|exit_locked|exit_open|win|game_over
// 初始 state=MENU、mode=HUMAN。
```

### 4.6 `collectibles.js` / `hazards.js` / `exit.js`（C，内部模块）

- 由 `gameplay.js` 统一创建/重置/更新；**不得各自操作 DOM、创建主循环、直接切 GAME_STATE**。
- 通过返回值/事件交给 `gameplay.js`。晶体的收集顺序严格按方案第五、七节：
  靠近(`IN_RANGE`) → 一次 `interactPressed` → `COLLECTING` 发 `dig` + `playAction('collect', collectDuration, {lockMovement:true})` → 等 `collectDuration` → `COLLECTED` 发一次 `collect`。

### 4.7 `ui.js`（C）— `createUI(callbacks)`

```js
{ render(sessionSnapshot, audioSnapshot), setInputDevice(device), announce(text, kind), dispose() }
// callbacks: onStart,onDemo,onPause,onResume,onRestart,onMenu,onVolumeChange,onMute
// 已固定 DOM ID：game-container,start-button,demo-button,pause-button,resume-button,
//   restart-button,menu-button,hud,objective,progress,health,interaction-prompt,
//   menu-screen,pause-screen,result-screen,volume-slider,mute-button,demo-badge
```

### 4.8 `audio.js`（C）— `createAudio()`

```js
{ unlock(), play(eventType), setVolume(0..1), toggleMute(),
  getSnapshot(), /* { volume, muted } */ reset(), dispose() }
// 不得依赖远程 URL；unlock() 在用户点击后调用，失败不阻塞游戏。
```

### 4.9 `demo.js`（C）— `createDemoController({ level, session })`

```js
{ reset(), readFrame(playerSnapshot, cameraYaw), isFinished(), stop() }
// readFrame 用「LEVEL.demoRoute + 真实快照 + 当前 cameraYaw」生成 InputFrame，
// 通过正常移动/互动/计数/开门/胜利完成；禁止瞬移、直接改 state/collected。
```

## 5. 主循环与启动/重开（`main.js`，A，已接通）

模块创建顺序与每帧顺序已按方案第八节实现，A 维护。要点（给 B/C 排查时参考）：
- `startRun(mode)` 统一：`audio.unlock → input.reset → audio.reset → environment.reset → player.reset(LEVEL.spawn) → camera.reset → session.start(mode) → demo 处理 → elapsed=0`。
- 每帧：`readFrame` → 全局键(Esc/Demo退出) → `PLAYING` 时按模式选 `demo.readFrame(...)` 或 `globalInput` → `player.update → camera.update → session.update → environment.update` → 分发事件 → `ui.render → renderer.render`。
- `window.blur`：清空输入；HUMAN+PLAYING 自动暂停。
- `window.resize` 只注册一次。
