## 2. 打开与操作

最直接：下载根目录 `遗迹回声_新素材整合版.html`，用新版 Chrome/Edge 打开；菜单标识 **R2 + C 完整功能版 C2**。另一个 `遗迹回声_B验证版.html` 为同内容兼容文件名。模型、纹理、Three.js、源码、样式和关卡均内嵌，不需外网。网页平台若显示源代码，请先下载到本机。

源码版在游戏根目录：

```bash
pnpm install --frozen-lockfile   # 已有依赖时不必重复
pnpm start                     # 默认 http://localhost:5173/
```

- WASD/方向键移动，按住鼠标左/右键拖动镜头，Shift跑步，Space跳跃，靠近金色标记站稳按E。
- 人工Esc暂停/继续；Demo Esc退出。Demo需暂停请用HUD暂停按钮或手柄Start，返回菜单请用退出/菜单按钮。
- 右下全局音量与静音，帮助会暂停进行中的游戏；关闭帮助后需明确继续。
- 自动演示约52秒，经两段楼梯下至第三层，全程使用同一角色移动和玩法，不是视频。
- 三层宝物脚底锚点分别在 y=0/-5/-10；第一枚土堆2.3米、两木盒1.9米范围，以屏幕提示为准。

## 6. C2 穿模修复专节

**根因**：碰撞数据（manifest.colliders 共 90 个 AABB）只覆盖墙体/家具/门柱，未覆盖楼梯梯体。两段楼梯在可视上是实心踏步块，但碰撞只有行走斜坡面，没有侧面与顶端背面；另有多处散件可视无碰撞。

**C2 补丁内容（`assets/level-manifest.json` 数据，51 条，`patch:'C1-clip-fix'` 标记）**：

- 每段楼梯：两条全高侧护栏（对齐栏杆柱/斜栏，阻断从上层井口侧面跌入和从下层侧面走进梯体）、一条顶端背面（对齐第一节实心踏步，阻断下层从梯顶下方走入）、井口两侧压顶石矮栏（对齐可视，0.3m）。
- 出口关闭石门（`Exit_Closed_Visual`）精确碰撞：未收齐时身体停在石门前；解锁后 WIN 触发区在石门之前，不受影响。
- 厨房墙面搁架（头部高度）精确碰撞。
- 蓄水池入口间隙封堵：原碰撞在入口留了 3m 豁口，但可视池壁是完整一圈；池内无玩法内容，按可视封堵。
- 全部 38 个周边碎石精确碰撞：高于步高容差 0.24m 的自然阻挡，较矮的成为可踏上的矮坎（与可视一致）。

**设计保留（不修）**：两处洞口警示沿仅 0.1m 且洞口本就是设计的坠落通道，保持可通行；墙脚线探测证实无法进入；行走坡面与踏步间最多 0.2m 的悬浮感来自“连续坡面 vs 踏步”数据设计，不属穿模，不改 A 的楼梯数据。

**修复中发现的自引入回归及处理**：顶端背面初版顶面对齐踏步顶（-0.2），梯面行人在距顶 0.92m 处被高出脚底 0.26m 的阻挡面卡住（旧楼梯测试断言余量 0.5 掩盖了该问题）。已将顶面降到上层地面以下 0.5m，并把专项断言收紧到 0.15m 余量；上行实测现在到达 y=0/z=14 完全走出梯口。

**验证**：`穿模扫描与验证.mjs` 对 13 组候选簇物理探测全部通过、楼梯 10 项专项断言通过；一键检验其余全部用例（含 Demo 四帧率通关、楼梯上下、出口/挖掘/复位回归）退出码 0；两 HTML 已按 C2 重建且内容一致。**用户随后反馈第 5 节第 10 项人工视觉复测已完成（通过）**——本记录依据用户口述，非代理自行浏览器验证；未附逐项截图/录像，不补写测量数据。至此第 5 节清单仅剩真实手柄硬件未实测（环境无手柄，不标兼容）。
