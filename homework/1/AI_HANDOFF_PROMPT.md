# 《遗迹回声 / Echoes of the Buried Relic》团队开发交接提示词

> 这份文件是给后续 AI 编码助手和组员使用的项目 brief。请先阅读完整文件，再修改代码。不要一次生成全部代码；按阶段实现、运行和测试。

## 1. 项目目标

我们正在完成第五周小组作业：使用 **HTML、CSS、JavaScript 和 Three.js** 制作一个可在浏览器运行的原创第三人称 3D 游戏。

游戏暂定名为 **《遗迹回声》**（英文可用 **Echoes of the Buried Relic**）。玩家扮演一名原创女性遗迹探险者，在古代遗迹中寻找三个被掩埋的发光宝物，避开障碍，激活出口并完成一个约 3–5 分钟的完整关卡。

必须保持原创：不能复制《Tomb Raider》或其他商业游戏的角色、名称、地图、服装设计、音乐、模型、纹理、剧情、标志或受版权保护的素材。优先使用 Three.js 程序生成的几何体、颜色、灯光和 Web Audio API 音效。

## 2. 必须实现的游戏功能

- 真实 Three.js 3D 场景和第三人称摄像机。
- 一个可玩的完整关卡，包含入口、遗迹区域、机关房和出口。
- 女探险者角色：简单脸部、头发、探险服装/长外套、围巾、手套、靴子和小背包。以服装作为主要可见模型，不需要真实人体或复杂身体细节。
- 角色的手臂和腿必须在走路/跑步时有明显姿势变化。
- 三个被沙土、碎石或石盒部分掩埋的发光宝物/晶体。
- 玩家靠近宝物时显示 `按 E / X 挖掘` 等提示；互动后角色做下蹲/伸手动作，宝物升起、变亮、旋转并被收集。
- 至少两个简单障碍或陷阱。
- 收集进度、目标提示、成功/失败反馈。
- 开始菜单、正常游戏、暂停、重新开始、胜利和失败流程。
- 音效或环境声音，以及静音/音量控制。
- 菜单中的明确 `观看演示 / Demo` 按钮。Demo 必须驱动真实游戏逻辑，展示移动、至少一次宝物挖掘、出口开启和完成流程，不能使用预录视频。
- 游戏不能依赖登录、实时 AI 服务、远程后端或外部服务才能游玩。
- 支持键盘、鼠标和浏览器 Gamepad API 手柄。

## 3. 角色设计与动画要求

使用简单的 Three.js Group 和几何体构建角色。建议层级：

```text
character (THREE.Group)
├── body/coat
├── head
├── hair
├── scarf
├── backpack
├── leftArmPivot  -> sleeve + glove
├── rightArmPivot -> sleeve + glove
├── leftLegPivot  -> trouser/coat section + boot
└── rightLegPivot -> trouser/coat section + boot
```

至少实现这些动画状态：

- `idle`：轻微呼吸和肩膀移动。
- `walk`：左右腿交替；左腿向前时右臂向前，右腿向前时左臂向前；身体轻微上下起伏。
- `run`：更大的摆臂和腿部幅度，速度更快。
- `jump/fall/land`：跳跃时手臂略抬高，落地时身体短暂下沉。
- `collect`：面向宝物下蹲并伸手。
- `interact`：向机关伸手。
- `hurt`：受到陷阱影响时后退/防御姿势。
- `victory`：完成后抬手庆祝。

优先使用程序动画（`Math.sin`、pivot rotation、简单位置变化），不要引入复杂骨骼系统或真实布料模拟。外套、围巾和背包可以用轻微摆动模拟动作。

## 4. 宝物/晶体互动要求

宝物不是简单漂浮的物体，而是埋在遗迹地面中的古代宝藏：

1. 初始状态：晶体只有一部分露出沙土/碎石，微弱发光。
2. 玩家靠近：显示互动提示。
3. 玩家按 `E` 或手柄 `X/Square`：触发真实收集流程。
4. 角色执行 `collect` 动画。
5. 沙土/碎石轻微移动或缩放，晶体升起。
6. 晶体变亮并旋转，播放收集音效。
7. HUD 从 `0 / 3` 更新到对应进度。
8. 宝物被标记为已收集，不可重复收集。

Demo 模式必须调用与人工游玩相同的宝物收集函数，至少展示一次完整挖掘动画。

## 5. 统一输入设计

所有设备必须写入同一个输入状态，玩家移动逻辑不得为不同设备复制多套：

```js
const input = {
  moveX: 0,
  moveY: 0,
  lookX: 0,
  lookY: 0,
  jumpPressed: false,
  interactPressed: false,
  sprintHeld: false,
  pausePressed: false,
  confirmPressed: false,
  cancelPressed: false
};
```

建议映射：

| 功能 | 键盘/鼠标 | 手柄 |
|---|---|---|
| 移动 | WASD/方向键 | 左摇杆 |
| 镜头 | 鼠标移动 | 右摇杆 |
| 跳跃/确认 | Space/鼠标左键 | A/Cross |
| 互动/挖掘 | E | X/Square |
| 冲刺 | Shift | 左摇杆按下 |
| 暂停 | Esc | Menu/Start |
| 取消/返回 | Esc/右键 | B/Circle |

Gamepad 读取使用 `navigator.getGamepads()`，需要设置约 `0.15` 的摇杆死区，并处理手柄连接/断开。记录最近使用的输入设备，以便显示相应操作提示。

## 7. 推荐实现阶段

1. 创建项目骨架、启动页面和 Three.js 场景。
2. 实现地面、墙、石柱、入口、出口和灯光。
3. 实现女探险者的几何体层级、第三人称相机和基础移动。
4. 实现键盘/鼠标输入，再加入 Gamepad API，并统一到 `input` 对象。
5. 实现 idle、walk、run、jump 等程序动画。
6. 实现三个掩埋宝物、互动提示、挖掘动画和 HUD 计数。
7. 实现障碍/陷阱、机关和出口。
8. 实现开始、暂停、失败、胜利和重新开始流程。
9. 实现 Web Audio 音效、背景环境声和静音/音量控制。
10. 实现真实游戏逻辑驱动的 Demo 模式。
11. 编写实际运行说明、浏览器测试结果、手柄说明和已知限制。
12. 每完成一个阶段都实际运行，检查控制台错误和游戏行为。
